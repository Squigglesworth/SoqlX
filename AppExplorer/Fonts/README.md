# Bundled fonts

Registered automatically at launch via `ATSApplicationFontsPath` in Info.plist.

- **Inter** (variable, weight 100-900), PostScript name `Inter-Regular`. Copyright The Inter Project Authors.
- **JetBrains Mono** (variable, weight 100-800), PostScript name `JetBrainsMono-Regular`. Copyright The JetBrains Mono Project Authors.
